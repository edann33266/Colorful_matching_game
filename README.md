# 🌈 Emoji Memory Match Game

A fun, colorful, and interactive **emoji-based memory matching game** built using **HTML, CSS, and JavaScript**.

Match emoji pairs before the timer runs out while enjoying smooth animations, glowing UI.

---

## 🎮 Live Demo

https://edann33266.github.io/Colorful_matching_game/

---

## ✨ Features

✅ Interactive emoji memory game  
✅ Timer with animated progress bar ⏱️  
✅ Score tracking system 🏆  
✅ Best score saved using Local Storage ⭐  
✅ Restart and replay functionality 🔄  
✅ Responsive design (Mobile + Desktop) 📱  
✅ Smooth hover animations and UI effects ✨  
✅ Win popup with stats 🎉  
✅ Modern glassmorphism + gaming-inspired UI 🎮
